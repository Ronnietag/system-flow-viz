# 验收清单
> 🇬🇧 **English readers**: this reference is the Chinese edition; see
> [`../README.en.md`](../README.en.md) for the English overview.

逐条打勾。任一条不过，交付就不算完成。

## 事实层

- [ ] 每个节点都有 `src`，且 `file:line` 我**亲自核对过**（不是子代理说核对过就算）
- [ ] 每个 `src.line` 落在该文件实际行数范围内（校验器已查，但抽样人工再核一遍）
- [ ] 所有行数、金额、条数类数字都带采集日期
- [ ] 实测数字来自**只读**连接，没写库、没改数据
- [ ] 文档与代码的冲突全部标了 ⚠，且写明「文档说 X / 代码是 Y / 出处」
- [ ] 历史留痕目录里的数字标为「当时的事实」，没按现状改写
- [ ] 取证边界显式声明（哪些没取到、为什么），没写成「全过」
- [ ] 「实测」与「文档转述」两类来源可区分
- [ ] 没查到的项写「未取到 + 原因」，没有推断或补齐

## 结构层

- [ ] 每个节点七块齐全：做什么 / 触发方式 / 源码位置 / 读表·写表·关键字段 / 输入→输出 / 失败与边界 / 文档锚点与冲突
- [ ] 每个写表都标了落库语义，且语义与源码 SQL 一致
- [ ] 视图引用的节点 id 全部存在，连线两端不缺
- [ ] 视图覆盖了需求里的**全部**功能面，没有「无死角」漏项
- [ ] 归档物（一次性脚本、历史文档）在图里，且样式与现行路径区分开

## 交互层

- [ ] **点节点弹说明框**，七块逐块可见
- [ ] **悬停节点 ⇒ 相关连线变高亮色**
- [ ] **高亮时线型不变**（虚线仍是虚线 —— 线型表达语义，高亮表达「与当前节点相关」，两者正交）
- [ ] **业务中文在图上、实际英文名在悬浮提示里**（图上不出现裸英文标识符）
- [ ] **悬浮提示不被节点/弹框挡住**（提示的 z-index 高于弹框；antd 默认 1070 常不够）
- [ ] 能**逐层往下钻**（点节点 → 弹框 → 点框里的项 → 下一层）
- [ ] 搜索能命中节点标题、表名、字段名、端点路径、文件路径
- [ ] 按层可折叠，折叠后仍能看到该层节点数
- [ ] 思维导图与流程图切换后**节点集合完全一致**（不丢节点）
- [ ] 浅色/深色跟随系统，打印样式可用
- [ ] 控制台无报错

## 画法层（硬规则）

- [ ] 连线**垂直于**所碰的那条边进出
- [ ] 连线**不贴着节点边缘横跑**（skill 原文：a horizontal segment that starts on a
      top or bottom edge runs along the border behind the node fill）
- [ ] 共享边**分点**，相邻 ≥12px，不许两条线共用一个点
- [ ] 连线**先画、节点后画**（节点底色遮住线头）
- [ ] 节点内文字**按内容块垂直居中**，不是写死的偏移
- [ ] 子标签**不溢出盒子**（SVG 文字不换行不截断 ⇒ 会静默被切）
- [ ] 宽度**按容器实测**（1:1 铺满），窄了才横滚

## 验证层

- [ ] `tsc --noEmit` 0 错、构建成功
- [ ] **引用校验器**（`templates/verify_refs.py`）退出码 0：源码位置存在、行号在范围内、
      节点 id 唯一、连线两端节点都存在、实测数字带日期、无占位符残留
- [ ] 校验器**故意造过几类错**并确认能抓（红→绿），修回后退出码归零
- [ ] 真实环境起过服务、跑过既有冒烟脚本、浏览器逐页截图
- [ ] **交互也截图**（悬停高亮、点开弹框 —— 交互坏了静态截图看不出来）
- [ ] 真实响应与界面数字已回写清单

## 交付层

- [ ] 仓库根 README 与 AGENTS.md 各加一行指路
- [ ] 说明文件写清：怎么改数据源、怎么重跑、字段什么意思、事实基准怎么守
- [ ] 规格与工单落在 issue tracker，状态标对
- [ ] **按用户的要求决定要不要 git 提交**（用户说「不提交」就不要提交）
- [ ] 页面可离线打开：零外链、零 CDN、零网络请求

## 沉淀层（要做 skill 时）

- [ ] SKILL.md 含 name + description（触发词覆盖中英文与用户可能的说法）
- [ ] 流程正文写清了每一路勘察要产出什么
- [ ] 红线写死：源码位置必填、实测带日期、冲突按代码写、查不到就写未取到
- [ ] 事实采集脚本随 skill 分发
- [ ] 模板随 skill 分发（清单骨架 + 组件模板 + 校验器）
- [ ] **装到通用技能目录，换个目录也能被加载**
- [ ] ⚠️ **skill 本体在版本控制里**（放仓库 `docs/skills/<name>/`，
      通用技能目录里做**软链**指向它）⇒ 换机器不丢、能 review、不会被改坏
- [ ] **路线变更时同步改 skill**（本 skill 就改过一次：静态 HTML → React 组件）
